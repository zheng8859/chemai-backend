---

为 ChemAI 教师端障碍诊断面板创建一个单文件 HTML（diagnosis.html）。所有数据为静态数据，无 API 调用，无 JavaScript 框架。使用内联 CSS（放在 `<style>` 标签内），仅用原生 JavaScript 处理折叠面板交互。页面面向 1280px+ 桌面视口。

## 全局
- 全视口高度，页面级不滚动——内部内容区域独立滚动。
- Flexbox 纵向排列：56px 顶部页头、工具栏、下方弹性可滚动内容区域。

- 圆角规则：卡片 8px，芯片 16px

## JavaScript 要求
- **Accordion 折叠**：点击 `.accordion-header` 时，获取其父元素 `.accordion-section`。若该区段已展开（含 `open` 类），则折叠它（移除 `open` 类，设置 `max-height: 0`）。若该区段已折叠，则先折叠所有兄弟区段（移除所有 `open` 类，全部设 `max-height: 0`），再展开当前区段（添加 `open` 类，设置 `max-height` 为 `scrollHeight + 'px'`）。
- **学习计划面板折叠**：独立的折叠函数，点击 `.plan-header` 时切换其父元素 `.plan-panel` 的 `open` 类并切换 `max-height`（不需要联动 accordion）。
- 页面加载时初始化默认展开区段的 `max-height`（IIFE 中执行）。
- 所有 JavaScript 为原生 JS，不使用任何框架。

## 设计润色
- 可交互元素使用 `transition: all 0.2s ease`。
- 全局使用 `box-sizing: border-box`。
- 折叠动画使用 `transition: max-height 0.35s ease`。
- 自定义滚动条：6px 宽，`rgba(0,0,0,0.15)` 滑块。
- 温暖、专业、学府风格——高级教育科技产品质感。
