# OCR 答题卡批改（ocr.html）提示词

将以下内容完整复制并粘贴到你使用的 AI 工具中。

---

为 ChemAI 教师端 OCR 答题卡批改面板创建一个单文件 HTML（ocr.html）。所有数据为静态数据，无 API 调用，无 JavaScript 框架。使用内联 CSS（放在 `<style>` 标签内），少量原生 JavaScript 用于切换开关交互。页面面向 1280px+ 桌面视口。

## 全局
- 全视口高度，页面级不滚动——内部内容区域独立滚动。
- Flexbox 纵向排列：56px 顶部页头、可滚动主内容区、底部固定操作栏。
- 主色：`#002045`（牛津蓝）
- 强调色：`#13696a`（深青）
- 背景色：`#faf8f5`（暖纸色）
- 标题字体：`'Cormorant Garamond', serif`（Google Fonts）
- 正文字体：`'IBM Plex Sans', sans-serif`（Google Fonts）
- 圆角规则：卡片 8px，芯片 16px
- 表格分隔线：`1px solid #e0e0e0`

## 顶部页头（56px，白色背景）
- 左侧：品牌 "ChemAI 智辅化学"（Cormorant Garamond，牛津蓝）+ 六边形 SVG 图标 + 面包屑导航"对话 / OCR 答题卡批改"。品牌链接到 index.html。
- 右侧："李老师"文字 + 32px 圆形头像，内写 "李"，牛津蓝背景。
