# ChemAI 教师端 AI Agent 对话面板提示词

将以下内容完整复制并粘贴到你使用的 AI 工具中。

---

创建一个名为 "ChemAI 智辅化学" 的教师端 AI 对话面板单文件 HTML（index.html）——一个化学教学助手。所有数据为静态数据，无 API 调用，无 JavaScript 框架。使用内联 CSS（放在 `<style>` 标签内）。页面面向 1280px+ 桌面视口。

## 全局布局
- 全视口高度，页面级不滚动——内部各区域独立滚动。
- Flexbox 横向排列：左侧固定 240px 深色侧边栏，右侧弹性聊天主区域填满剩余宽度。

## 色彩与字体
- 主色：`#002045`（牛津蓝）
- 强调色：`#13696a`（深青）
- 聊天区背景：`#faf8f5`（暖纸色）
- 侧边栏背景：`#1a1a2e`
- 标题字体：`'Cormorant Garamond', serif`（从 Google Fonts 加载）
- 正文字体：`'IBM Plex Sans', sans-serif`（从 Google Fonts 加载）
- 圆角规则：
  - 卡片和按钮：**8px**
  - 聊天气泡：**12px**
  - 快捷提示芯片：**16px**

---

## 1. 左侧边栏（240px，`#1a1a2e` 背景）
- 固定宽度 240px，全高度，flex-column 布局。
- **品牌 Logo** 位于顶部："ChemAI 智辅化学"，白色，使用 Cormorant Garamond 字体，20px，加粗，旁边放置六边形或原子风格的小图标。
- **"新建对话"按钮**：全宽（减去水平内边距），深青色 `#13696a` 背景，白色文字，8px 圆角，标签左侧带 "+" 图标。悬停状态稍亮。
- **对话历史列表**：5 条静态示例，每条显示：
  - 加粗标题（例如"氧化还原反应备课"、"月考成绩分析"、"期中试卷出题"、"元素周期表教学"、"学生错题汇总"）
  - 标题下方较小的灰色时间戳（例如"今天 14:30"、"昨天 09:15"、"7月28日"、"7月25日"、"7月20日"）
  - 每条 8px 圆角，悬停背景 `rgba(255,255,255,0.08)`，激活/选中状态（首条高亮）。
  - 超出时列表独立滚动（flex-grow，overflow-y: auto）。
- **底部导航栏**（侧边栏内部最底部）：4 个图标按钮水平均匀排列：
  - 首页、工作台、学情、设置
  - 使用简单的 SVG 图标或 Unicode 符号。白色/灰白色。每个图标下方小标签。
  - 激活图标为深青色；其余为 `rgba(255,255,255,0.5)`。

---

## 2. 主聊天区域（`#faf8f5` 背景）
Flex-column，全高度。从上到下包含以下区块：

### 2a. 上下文标签栏（顶部，水平）
- 一条浅色横条（浅灰 `#f0ece6` 或相近色），以胶囊形标签显示当前教学上下文：
  - "📘 当前班级：高一(3)班"，右侧带 "✕" 关闭图标。
  - 白色背景，8px 圆角，轻微阴影或边框。
- 横条右侧：一个"清除上下文"或"设置"图标按钮。

### 2b. 消息列表（flex-grow，可滚动）
包含 4 条消息，纵向堆叠排列（间距 16px）：

**消息 1 — AI（左对齐）：**
- 头像：左侧 36px 小圆形，内写 "AI" 或机器人图标，深青色背景。
- 气泡：`#e0f2f1` 背景（浅青），12px 圆角，最大宽度约 70%。正文字体。
- 内容："您好！我是 ChemAI 智辅化学助手。我可以帮您出题、分析学情、总结知识点，请随时告诉我您的需求。"
- 下方小时间戳："14:28"

**消息 2 — 用户（右对齐）：**
- 头像：右侧 36px 小圆形，内写 "师"（代表老师），牛津蓝背景，白色文字。
- 气泡：白色背景，1px 实线 `#d4d0c8`（或 `#e0e0e0`）边框，12px 圆角，最大宽度约 70%。
- 内容："帮我出3道关于氧化还原反应的选择题，难度中等，适合高一学生。"
- 下方小时间戳："14:29"

**消息 3 — AI（左对齐），内嵌工具调用卡片：**
- 头像和气泡样式与消息 1 相同。
- 气泡内容以简短文字开头："好的，正在为您生成题目…"
- 文字下方放置**内嵌工具调用卡片**：
  - 独立卡片样式：稍内嵌，背景 `#ffffff`，8px 圆角，1px 实线 `#b2dfdb`（或 `#d4d0c8`），左侧 3px 实线深青色 `#13696a` 强调边。
  - 标题行：小 ⚙️ 图标 + 加粗标签"工具调用: generate_quiz"，使用等宽或代码风格字体。
  - 内容行：参数摘要，紧凑双栏格式，例如：
    ```
    topic: 氧化还原反应
    count: 3
    type: 选择题
    difficulty: 中等
    grade: 高一
    ```
  - 卡片下方简短状态行："✓ 已完成 · 用时 1.2s"，小号绿色/灰色文字。
- 下方小时间戳："14:29"

### 2c. 快捷提示芯片（水平行）
- 一行 6 个预设提示按钮，允许换行但空间允许时优先单行排列。
- 每个芯片：白色背景，1px 实线 `#d4d0c8` 边框，16px 圆角，8–12px 水平内边距，32px 高，正文字体 13px，颜色 `#333`。
- 悬停：背景变为 `#e0f2f1`，边框颜色 `#13696a`。
- 6 个标签：
  1. "⚡ 出3道氧化还原题"
  2. "📊 分析班级月考成绩"
  3. "📝 最近考试错题统计"
  4. "📋 生成知识点总结"
  5. "💡 推荐教学策略"
  6. "🔍 查看学生薄弱点"

### 2d. 化学式工具栏（水平行，输入框上方）
- 紧凑一行 6 个小图标按钮，用细分隔线或 4px 间距隔开：
  1. **H₂O**（水分子，用 `<sub>` 实现下标：H<sub>2</sub>O）
  2. **→**（右箭头——反应）
  3. **↑**（上箭头——气体）
  4. **↓**（下箭头——沉淀）
  5. **△**（三角——加热符号）
  6. **···**（更多/展开）
- 每个按钮：28-32px 正方形，白色背景，1px 实线 `#d4d0c8`，8px 圆角，图标/文字居中。悬停：边框色 `#13696a`，背景 `#e0f2f1`。

### 2e. 输入区域（水平 flex 行）
- 多行文本输入（`<textarea>`）：flex-grow，最小高度 44px，最大高度 120px，自适应调整。白色背景，1px 实线 `#d4d0c8`，8px 圆角，placeholder 文字"输入您的教学问题…"（灰色）。IBM Plex Sans，14px。内边距 10-14px。
- **附件图标按钮**（回形针 📎）：36px 正方形，透明背景，灰色图标，8px 圆角。悬停：背景 `#e0f2f1`。
- **发送按钮**：40px 圆形，牛津蓝 `#002045` 背景，白色向上/向右箭头图标（可用 SVG 或 Unicode "➤"）。50% 圆角（正圆）。悬停：稍浅蓝色 `#003366`。

### 2f. 状态栏（底部，输入区下方）
- 一条简洁行：小绿点（● `#4caf50`）+ "就绪"，灰色文字，正文字体 12px，颜色 `#888`。
- 右侧：可选 "ChemAI v2.1 · GPT-4o" 版本/标签文字，更小的灰色样式。

## 设计润色
- 为侧边栏（右侧边缘）和聊天气泡添加轻微 `box-shadow`（极轻，例如 `0 1px 3px rgba(0,0,0,0.06)`）。
- 可交互元素使用 `transition: all 0.2s ease` 实现平滑悬停效果。
- 整个页面应呈现温暖、专业、学府风格——高级教育科技产品的质感。
- 确保正确的滚动行为：侧边栏历史列表和主消息列表各自独立 `overflow-y: auto`。
- 全局使用 `box-sizing: border-box`。
- 侧边栏与聊天区域之间添加细右边框或轻微阴影分隔。

## 输出
返回完整的 `index.html` 文件，放在单个代码块中。必须可直接在浏览器中打开，无需构建步骤，除 Google Fonts CSS 外无外部依赖。所有内容为上述中英混合静态内容。
