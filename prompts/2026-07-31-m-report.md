# 学生端个人报告与设置页（m/report.html）提示词

将以下内容完整复制并粘贴到你使用的 AI 工具中。

---

为学生端创建个人报告与设置页面的单文件 HTML（pages/m/report.html）。所有数据为静态数据。使用内联 CSS，原生 JavaScript 实现底部弹出弹窗。页面面向移动端 390px 视口。

## 全局
- `max-width: 390px`，水平居中，100vh，flex-column。
- 主色 `#002045`（牛津蓝），背景 `#faf8f5`。
- 字体：标题 Cormorant Garamond，正文 IBM Plex Sans，绑定码 JetBrains Mono。

## 组件

### 1. 顶部标题栏（56px，牛津蓝背景，白色文字）
- 左侧"我的"（16px，font-weight 600）
- 右侧齿轮设置图标 ⚙（SVG）

### 2. 个人信息卡片（白色背景，8px 圆角，margin 16px，padding 20px，text-align: center）
- 头像：80×80px 圆形，灰色 `#e0e0e0` 背景，居中显示首字"张"（28px 灰色 `#888`）
- 姓名"张三"（18px bold，牛津蓝，margin-top 12px）
- 班级"高一(3)班"（14px，灰色 `#888`，margin-top 4px）
- 绑定码（margin-top 12px，inline-flex，gap 6px）："绑定码"（12px 灰色）+ "X7K2M9"（JetBrains Mono 14px，`#f5f5f5` 背景，4px 8px padding，4px 圆角）

### 3. 学习统计三列（白色卡片，8px 圆角，margin 0 16px 16px，padding 16px 8px，flex 3 等宽）
每列 text-align: center：
- 完成练习：**85**（22px bold 牛津蓝）+ "完成练习"（12px 灰色）

5 个列表项，每项 height 48px，padding 0 16px，flex justify-between align-center，底部 `1px solid #f0f0f0`：

| 项 | 右侧装饰 |
|----|---------|
| 学习报告 | 红色 badge"新"（10px 白色文字，红色 `#e53935` 背景，圆角）+ 灰色箭头 > |

| 我的错题本 | 灰色圆形 badge"23"（12px，`#f0f0f0` 背景，22px 圆）+ 箭头 > |

### 5. 学习周报弹窗（默认隐藏，点击"学习报告"触发）

**遮罩层**（`position: fixed; inset: 0; background: rgba(0,0,0,0.4); z-index: 200`）：
- 默认 `opacity: 0; pointer-events: none`，`.show` 时 `opacity: 1; pointer-events: auto`
- `transition: opacity 0.3s`
- 点击关闭

**底部弹出卡片**（`position: fixed; bottom: 0; left: 0; right: 0; max-height: 70vh; z-index: 201`）：
- 白色背景，`border-radius: 16px 16px 0 0`，`overflow-y: auto`
- 默认 `transform: translateY(100%)`，`.open` 时 `translateY(0)`，`transition: 0.3s`

弹窗内容：
- **标题行**：flex justify-between，padding 20px 20px 12px
  - "学习周报（7月第1周）"（Cormorant Garamond，18px bold）
  - 关闭按钮 ✕（28px 圆形，`#f0f0f0` 背景）
- **统计概览**（flex 3 列，gap 8px，`#fafafa` 背景，8px 圆角，padding 14px 8px）：
  - 本周练习 25 / 正确率 76% / 学习时长 3.2h（24px bold 牛津蓝 + 12px 灰色标签）
- **知识点掌握度**（h3 14px bold + 5 条进度条）：
  每行：知识点名称（13px 灰色，70px 宽）+ 灰色进度条（6px 高，`#e8e8e8` 底，牛津蓝填充）+ 百分比数字（12px）
  - 氧化还原 85%、离子反应 72%、化学键 68%、化学平衡 55%、电化学 60%
- **教师评语**（14px 灰色，`#fafafa` 背景，8px 圆角，12px padding，line-height 1.7）："张同学本周表现不错，氧化还原反应部分掌握较好..."
- **底部关闭按钮**（全宽 44px，`#f0f0f0` 背景，8px 圆角，margin-top 16px）

### 6. 底部 Tab 栏（56px）
- "我的"为激活态（牛津蓝）
- 4 tab：AI助教 / 练习 / 错题 / 我的(激活)

## JavaScript
```javascript
function openModal() { overlay.classList.add('show'); sheet.classList.add('open'); }
function closeModal() { overlay.classList.remove('show'); sheet.classList.remove('open'); }
```
- 点击"学习报告"菜单项调用 `openModal()`
- 点击遮罩层或关闭按钮调用 `closeModal()`

## 输出
返回完整的 `pages/m/report.html` 文件，可直接在浏览器中打开。
