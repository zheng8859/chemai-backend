# ChemAI 智辅化学 · Google Stitch 提示词存档

## 1. 教师端 AI Agent 对话主面板（index.html）

生成一个单文件 HTML 原型（index.html），用于桌面端 1280px+ 视口的教师端 AI Agent 对话主面板，产品名称为 "ChemAI 智辅化学"。所有数据为静态示例，不连接 API。使用内联 CSS，仅依赖 Google Fonts。

### 全局布局
- 全视口高度，禁止页面级滚动，内部面板独立滚动。
- Flexbox 行布局：左侧固定 240px 深色侧边栏（背景 #1a1a2e），右侧填充剩余宽度的对话主区域（背景暖纸色 #faf8f5）。

### 配色与字体
- 主色 Oxford Blue #002045，强调色 Teal #13696a，暖纸色背景 #faf8f5。
- 标题字体 Cormorant Garamond，正文字体 IBM Plex Sans（均从 Google Fonts 加载）。
- 圆角：卡片/按钮 8px，气泡 12px，芯片 16px。

### 组件要求
1. 侧边栏（240px，#1a1a2e）：品牌 Logo "ChemAI 智辅化学"（白色）+ Teal 色"新建对话"按钮 + 5 条对话历史（标题+时间戳，第一条高亮）+ 底部 4 个导航图标（首页/工作台/学情/设置，首页高亮）。
2. 对话区：顶部上下文标签"当前班级：高一(3)班" + 3 条消息（用户气泡右对齐白底灰边，AI 气泡左对齐 #e0f2f1 背景，圆角 12px）+ 1 条工具调用卡片（工具名 generate_quiz + 参数摘要）。
3. 快捷芯片：6 个预设提示按钮横向排列，白底灰边，圆角 16px。
4. 化学式预览栏：H₂O、→、↑、↓、△、··· 快捷按钮。
5. 输入区：多行文本框 flex-grow + 附件图标 + Oxford Blue 圆形发送按钮（白色箭头）。
6. Agent 状态栏：输入区下方显示"就绪"绿色圆点状态。

输出为可直接复制到 Google Stitch 的完整中文提示词描述。

## 2. 教师端学生管理（students.html）

生成一个单文件 HTML 原型（students.html），用于桌面端 1280px+ 视口的教师端学生管理页面。所有数据为静态示例，不连接 API。使用内联 CSS 与少量 JS，仅依赖 Google Fonts。

### 全局布局
- 页面从上到下依次排列：顶部深色导航栏、统计栏、搜索筛选栏、学生卡片网格、分页控件。
- 右侧详情抽屉固定定位，默认 right:-480px，点击卡片"详情"按钮后滑出（0.3s transition），宽度 480px，高度 100vh，带半透明黑色遮罩层（opacity 0.4），点击遮罩关闭。

### 配色与字体
- 主色 Oxford Blue #002045，强调色 Teal #13696a，背景暖纸色 #faf8f5，深色导航栏背景 #1a1a2e。
- 标题字体 Cormorant Garamond，正文字体 IBM Plex Sans。
- 圆角：卡片/按钮 8px，筛选 chip 16px。

### 组件要求
1. 顶部深色导航栏：品牌 Logo "ChemAI 智辅化学" + 导航链接（对话 / 学生管理高亮 / 成绩分析 / 设置）。
2. 统计栏：4 项横向排列——总人数 42 / 活跃学生 38 / 关注学生 5 / 班级平均 78.5；每项上方 12px 灰色标签，下方 24px bold Oxford Blue 数字。
3. 搜索筛选栏：全宽搜索框（placeholder "搜索学生姓名..."，8px 圆角）+ 筛选 chip 行（全部班级 / 高一(1)班 / 高一(2)班 / 高一(3)班 / 概念障碍 / 审题障碍 / 表述障碍 / 活跃状态）。
4. 学生卡片网格：grid-template-columns: repeat(3, 1fr)，间距 16px，共 6 张卡片。每张卡片白底、8px 圆角、16px 内边距，包含：40px 圆形灰色头像占位、16px bold 姓名、灰色班级小字、4px 高障碍分布条（概念紫色、审题蓝色、表述青色三段）、3 个成绩趋势小圆点（绿/黄/红）、Teal 色"详情"小号按钮。
5. 右侧详情抽屉：学生基本信息（姓名/学号/班级/入学时间）、障碍分布（三个彩色条形+百分比）、纯 CSS/SVG 成绩折线图（月份横轴+点连曲线）、薄弱知识点标签列表、底部操作按钮组（生成学习计划 / 发送通知 / 编辑信息）。
6. 分页控件：居中，包含上一页、页码 1 2 3 ... 8（当前页 Oxford Blue 背景白字）、下一页。
