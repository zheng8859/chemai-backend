# 教师端班级学情面板（teacher.html）提示词

将以下内容完整复制并粘贴到你使用的 AI 工具中。

---

为 ChemAI 教师端班级学情面板创建一个单文件 HTML（teacher.html）。所有数据为静态数据，无 API 调用，无 JavaScript 框架。使用内联 CSS（放在 `<style>` 标签内）。页面面向 1280px+ 桌面视口。

## 全局
- 全视口高度，页面级不滚动——内部内容区域独立滚动。
- Flexbox 纵向排列：56px 顶部页头、工具栏、下方弹性可滚动内容区域。
- 主色：`#002045`（牛津蓝）
- 强调色：`#13696a`（深青）
- 背景色：`#faf8f5`（暖纸色）
- 标题字体：`'Cormorant Garamond', serif`（Google Fonts）
- 正文字体：`'IBM Plex Sans', sans-serif`（Google Fonts）
- 圆角规则：卡片 8px，芯片 16px

## 顶部页头（56px，白色背景）
- 左侧：品牌 "ChemAI 智辅化学"（Cormorant Garamond，牛津蓝）+ 六边形 SVG 图标 + 面包屑导航"对话 / 班级学情"。品牌链接到 index.html。
- 右侧："李老师"文字 + 32px 圆形头像，内写 "李"，牛津蓝背景。

## 工具栏（页头下方，白色背景，1px 底边框）
- 两个下拉选择器并排，带标签：
  - "📘 班级"：预选"高一(3)班"，选项：高一(1)班 至 高一(5)班
  - "📅 时间范围"：预选"本学期"，选项：本学期 / 上学期 / 本学年 / 全部
- 每个 `<select>` 样式：8px 圆角，1px 实线边框，用 background-image SVG 实现自定义下拉箭头。

## 可滚动主内容区（flex-grow，overflow-y: auto，内边距 24px 32px，行间距 24px）

## 第三行 — 全宽成绩趋势图
区块卡片，标题"成绩趋势"。

纯 CSS 折线图，显示两条数据系列：
- **班级平均分**（牛津蓝 #002045 数据点 + 连线）
- **年级平均分**（深青色 #13696a 数据点 + 连线）

图表区域：约 260px 高，在 y=60、70、80、90 处绘制水平虚线网格线（左侧标签，11px 灰色）。

实现方式：
- 每个数据点为绝对定位的 10px 圆形（白色填充，彩色边框），置于正确的 (x, y) 坐标。
- 相邻数据点之间的线段为细条（2px 高）绝对定位的 `<div>` 元素，使用 `transform: rotate(角度)` 和 `transform-origin: 0 50%`。
- Y 轴将分数 60-90 映射到图表高度。
- X 轴标签（6 个月）：9月、10月、11月、12月、1月、6月——沿底部均匀分布。

数据点：

| 月份 | 班级平均分 | 年级平均分 |

| 9月 | 72 | 70 |
| 10月 | 75 | 72 |
| 11月 | 73 | 71 |
| 12月 | 80 | 75 |
| 1月 | 78 | 74 |
| 6月 | 82 | 76 |

图表下方的图例：两项（牛津蓝圆点 + "班级平均分"，深青圆点 + "年级平均分"），13px 灰色文字。

## 设计润色
- 可交互元素使用 `transition: all 0.2s ease`。
- 全局使用 `box-sizing: border-box`。
- 卡片悬停时添加轻微 `box-shadow`（`0 2px 8px rgba(0,0,0,0.08)`）。
- 自定义滚动条：6px 宽，`rgba(0,0,0,0.15)` 滑块。
- 温暖、专业、学府风格——高级教育科技产品质感。
- 所有图表使用纯 CSS/HTML div 实现——不使用 Chart.js，不使用任何外部图表库。
