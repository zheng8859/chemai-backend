# 考试工作台（exam-v2.html）提示词

将以下内容完整复制并粘贴到你使用的 AI 工具中。

---

为 ChemAI 教师端考试工作台创建一个单文件 HTML（exam-v2.html）——一个 4 标签页的单页应用。所有数据为静态数据，无 API 调用，无 JavaScript 框架（不使用 Vue/React/jQuery）。使用内联 CSS（放在 `<style>` 标签内），仅用原生 JavaScript 处理标签页切换。页面面向 1280px+ 桌面视口。

## 全局
- 全视口高度，页面级不滚动——内部各区域独立滚动。
- Flexbox 纵向排列：56px 顶部页头、标签栏、下方弹性内容区域。
- 主色：`#002045`（牛津蓝）
- 强调色：`#13696a`（深青）
- 背景色：`#faf8f5`（暖纸色）
- 标题字体：`'Cormorant Garamond', serif`（Google Fonts）
- 正文字体：`'IBM Plex Sans', sans-serif`（Google Fonts）
- 圆角规则：卡片 8px，按钮 8px，芯片 16px

## 顶部页头（56px）
- 左侧：品牌 "ChemAI 智辅化学"（Cormorant Garamond，牛津蓝）+ 六边形图标（SVG）+ 面包屑导航"对话 / 考试工作台"。品牌链接到 index.html。
- 右侧："李老师"文字 + 32px 圆形头像，内写 "李"，牛津蓝背景，白色文字。

## 标签栏
- 4 个标签按钮："出题工作台"（默认激活）、"题库管理"、"历史真题库"、"考试列表"。
- 激活态：牛津蓝文字 + 2px 实线牛津蓝底部边框。非激活态：`#666` 文字，透明边框。
- JavaScript：点击标签按钮时显示/隐藏对应的 `<div>` 面板。激活面板添加 `active` 类。

## 标签页 1 — 出题工作台

### 子模式切换栏
- 3 个分段切换按钮："🤖 AI 生成" / "✏️ 手动录入" / "📷 OCR 导入"。
- 激活按钮：牛津蓝 `#002045` 背景，白色文字。
- 非激活：白色背景，`#666` 文字，1px 边框。
- JavaScript：点击切换激活状态（同一时间仅一个激活）。

### 控制卡片（白色背景，8px 圆角，1px 边框，20px 内边距）
- **题型芯片**：5 个芯片——选择题 / 填空题 / 计算题 / 方程式配平 / 实验探究。白色背景，灰色边框，16px 圆角。激活芯片为牛津蓝背景 + 白色文字。点击切换。
- **难度下拉框**：`<select>`，选项为 简单 / 中等 / 困难。
- **知识点搜索输入框**：全宽 `<input>`，左侧带搜索图标（SVG 放大镜），placeholder 为 "搜索知识点..."。
- **变体复选框**：`<input type="checkbox">`，标签为"生成变体（自动生成同知识点不同问法的变体题）"，默认勾选。
- **"生成题目"按钮**：全宽，48px 高，牛津蓝背景，白色文字，加粗，8px 圆角。

### 题目卡片（3 张静态示例卡片）
每张卡片：白色背景，1px 边框，8px 圆角，16px 内边距。

**卡片 1** — Q1 · 氧化还原反应方程式配平（选择题）
- 正文：已知反应：KMnO₄ + HCl → KCl + MnCl₂ + Cl₂↑ + H₂O，配平后 HCl 的系数是多少？A. 8 / B. 10 / C. 16 / D. 20
- 审核徽章：系数=✓ 通过, 条件=✓ 通过, 产物=⚠ 警告, 结构=✗ 阻断

**卡片 2** — Q2 · 化学键类型与分子极性判断（选择题）
- 正文：下列分子中，属于极性分子的是？A. CO₂ / B. CH₄ / C. H₂O / D. CCl₄
- 审核徽章：全部 4 项 = ✓ 通过

**卡片 3** — Q3 · 化学反应速率影响因素（计算题）
- 正文：某反应在 25°C 时的速率常数为 k₁，在 35°C 时速率常数为 k₂ = 3k₁，求该反应的活化能。
- 审核徽章：系数=✓ 通过, 条件=⚠ 警告, 产物=✓ 通过, 结构=⚠ 警告

### 审核徽章颜色
- **通过**：背景 `#e0f2f1`，文字 `#004f50`，图标 ✓
- **警告**：背景 `#fff3cd`，文字 `#856404`，图标 ⚠

### 题目卡片底部
- 左侧：审核徽章行。
- 右侧："编辑"和"收藏"图标文字按钮（小尺寸，1px 边框，8px 圆角）。

## JavaScript 要求
- **标签页切换**：点击 `.tab-btn`——移除所有按钮和面板的 `active` 类，为被点击的按钮及其目标面板（`data-tab` 属性匹配面板 `id`）添加 `active` 类。
- **子模式切换**：点击 `#modeToggle` 内的 `.mode-btn`——移除所有按钮的 `active` 类，为被点击的按钮添加。
- **芯片切换**：点击 `#questionTypeChips` 内的 `.chip`——同样的激活/非激活切换模式。
- **文件夹选择**：点击 `#folderList` 内的 `.folder-item`——同样的激活/非激活切换模式。
- 所有 JavaScript 为原生 JS，放在 `<body>` 底部的单个 IIFE 中，不使用任何框架。

## 设计润色
- 可交互元素使用 `transition: all 0.2s ease`。
- 全局使用 `box-sizing: border-box`。
- 卡片悬停时添加轻微 `box-shadow`（`0 2px 8px rgba(0,0,0,0.08)`）。
- 温暖、专业、学府风格——高级教育科技产品质感。
- 自定义滚动条：6px 宽，`rgba(0,0,0,0.15)` 滑块。

## 输出
返回完整的 `exam-v2.html` 文件，放在单个代码块中。可直接在浏览器中打开，无需构建步骤，除 Google Fonts CSS 外无外部依赖。所有内容为上述静态中文内容。
